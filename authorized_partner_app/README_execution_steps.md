# Signup Automation Submission

## Purpose
This folder is a clean workspace for the fully automated signup flow required for the internship task.

## Submission files
- `signup_automation_script.spec.js` - Playwright automation script.
- `README_execution_steps.md` - execution and setup notes.
- `Sample_business_registration.jpg` - business registration upload fixture.
- `Educational_certificate.pdf` - education certificate upload fixture.
- `test_report.pdf` - export the Playwright HTML report as a PDF if you need a final report file.
- `demo_video.mp4` - screen recording of the run for submission.

## How to run
Prerequisites:
- Node.js and npm installed.
- Playwright Test installed from the root `package.json`.
- Microsoft Edge installed locally because the project is configured to run with the `msedge` channel.
- A valid `MAILOSAUR_API_KEY` in a local `.env` file.

Commands:
1. Install dependencies:
   ```bash
   npm install
   ```
2. Run the Playwright test:
   ```bash
   npx playwright test internship_signup_submission/signup_automation_script.spec.js
   ```
3. Show the HTML report:
   ```bash
   npx playwright show-report
   ```

## Environment
- Language: JavaScript
- Framework: Playwright Test
- Playwright version: `@playwright/test` `^1.58.2`
- Browser project: Microsoft Edge via the `msedge` channel in `playwright.config.js`
- Test data source: Mailosaur OTP email verification using the server ID `wd2pmw4y`
- Local fixtures: `Sample_business_registration.jpg` and `Educational_certificate.pdf`

## Test data used
- First/last name, phone number, password, agency name, agency email, website, and address are generated by helper functions in `utils.js`.
- OTP validation is done through Mailosaur using the generated test email address.
- Fixed sample values used in the flow include `BRN123456`, `Nepal`, `India`, `Pakistan`, `15000`, `90`, and `Certified Business Partner`.
